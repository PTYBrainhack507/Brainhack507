Instalación en Kodi 21 (Omega)

  1. Ajustes → Administrador de archivos → Añadir fuente → URL: https://ptybrainhack507.github.io/Brainhack507/, nombre brainhack
  2. Add-ons → Instalar desde archivo zip → brainhack → repository.brainhack-1.0.0.zip
  3. Instalar desde repositorio → Brainhack Repository → Add-ons de vídeo → Brainhack → Instalar
